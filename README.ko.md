**공짜입니다.** 받아서 켜면 끝. 가입도, 결제도 없습니다.

**내 PC 안에서 받아씁니다.** 인터넷이 없어도 되고, 목소리가 밖으로 나가지 않습니다.

**말을 끊지 않습니다.** 말하는 대로 글이 보이고, 내가 멈출 때만 멈춥니다.

**멈추면 바로 들어갑니다.** 채팅창이든 문서든 코딩 도구든, 커서가 있던 그 자리에.

**키 하나면 됩니다.** `G`를 길게 누르면 켜지고, 다시 길게 누르면 꺼집니다. 짧게 누르면 평소처럼 g가 입력됩니다.

**마우스가 키보드가 됩니다.** 남는 버튼에 단축키를 걸어 두세요. Logitech 제스처에는 Enter, 붙여넣기, 복사도 연결할 수 있습니다.

**내가 정한 말로 켜고 끕니다.** 설정 → 내 목소리에서 등록하면 한마디로 시작하고 멈출 수 있습니다.

## 시작하기

1. 위 버튼으로 받아서 실행합니다.
2. 첫 실행 안내를 따라 인사하고, 마이크를 확인합니다.
3. “내 PC에서 (무료, 인터넷 불필요)” 또는 “Gemini API 키로”를 고릅니다.
4. 로컬은 음성 모델을 한 번 받습니다 (약 250MB 또는 1.1GB 중 선택). Gemini는 키를 입력합니다.
5. 안내에 따라 써 봅니다. `G` 키를 길게 누르고 말한 뒤 다시 길게 누르면 커서 자리에 붙여넣습니다.

## 더 정확하게 쓰고 싶다면

키가 없어도 **Gemini를 10초 동안 체험**해 볼 수 있습니다 (하루 3번). 첫 실행 안내나 설정에서 눌러 보세요.

설정에 Gemini API 키를 넣으면 Google의 음성 인식으로 받아쓸 수 있습니다. 키는 [Google AI Studio](https://aistudio.google.com/apikey)에서 무료로 받을 수 있고, 사용량은 Google의 무료 한도와 요금을 따릅니다. 이때는 목소리가 Google로 전송됩니다.

**Windows가 실행을 막아요.** 서명이 없는 프로그램이라 처음에 경고가 뜹니다. **추가 정보 → 실행**을 누르세요.

**내 글과 목소리는 어디에 남나요?** 받아쓴 글은 내가 고른 기록 폴더에 Markdown으로 저장됩니다 (기본: `문서\mulbit`). 기본 설정에서는 목소리를 저장하지 않습니다.

**G 말고 다른 키로 하고 싶어요.** 설정에서 바꿀 수 있습니다. `Alt+Shift+V` 같은 단축키도 따로 정할 수 있고, 마우스 프로그램(Logitech 등)에서 그 단축키를 버튼에 연결하면 됩니다.

**어떤 Windows에서 되나요?** Windows 10과 11.
