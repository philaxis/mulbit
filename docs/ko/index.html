무료 음성 인식 키보드, 물빛

말하면, 커서가 있는 자리에 글이 써집니다. 딸깍 한 번으로 켜고, 딸깍 한 번으로 끕니다.

⬇ Windows용 물빛 받기 — 무료

파일 하나. 설치도, 가입도, 결제도 없습니다.

공짜입니다

받아서 켜면 끝입니다. 가입, 구독, 기간 제한이 없습니다.

딸깍 한 번이면 됩니다

G 키를 길게 누르면 켜지고 다시 길게 누르면 꺼집니다. 짧게 누르면 평소처럼 g가 입력됩니다. 마우스의 남는 버튼에 단축키를 걸어도 됩니다.

커서가 있는 자리에 바로 써집니다

채팅창, 문서, 코딩 도구, 브라우저 어디든 멈추는 순간 커서 자리에 글이 들어갑니다.

내 PC 안에서 받아씁니다

음성 인식이 내 컴퓨터에서 돌아갑니다. 인터넷이 없어도 되고 목소리가 밖으로 나가지 않습니다.

말을 끊지 않습니다

말하는 대로 글이 보이고 내가 멈출 때만 멈춥니다. 한국어, 영어, 중국어, 섞어 말하기를 받아씁니다.

Gemini로 더 정확하게

내 Google Gemini API 키를 넣으면 더 정확한 인식을 쓸 수 있고, 키 없이 10초 동안 체험할 수도 있습니다.

시작하기

  1. mulbit.exe를 받아서 실행합니다.
  2. 첫 실행 안내를 따라 마이크를 확인합니다.
  3. “내 PC에서”를 고르면 음성 모델을 한 번 받습니다(약 250MB 또는 1.1GB). Gemini API 키를 넣어도 됩니다.
  4. G를 길게 누르고 말한 뒤 다시 길게 누르면 커서 자리에 붙습니다.

자주 묻는 것

정말 무료인가요?
네. 물빛은 무료 프로그램입니다. 가입이나 결제 없이 받아서 쓸 수 있습니다.
인터넷 없이도 되나요?
네. “내 PC에서” 받아쓰기는 음성 모델을 한 번 받은 뒤에는 아무것도 밖으로 보내지 않습니다.
어떤 Windows에서 되나요?
Windows 10과 11입니다. Mac과 Linux용은 실제 기기에서 시험하지 못한 미리보기가 릴리스 페이지에 있습니다.
Windows가 실행을 막아요.
아직 서명이 없는 프로그램이라 처음에 경고가 뜹니다. “추가 정보” → “실행”을 누르세요.
타자 대신 쓸 만한가요?
AI에게 길게 설명하거나 메신저 답장, 회의 메모처럼 말이 타자보다 빠른 일에 잘 맞습니다.

무료로 쓸 수 있습니다. 재배포와 수정은 안 됩니다.
